# RAGFlow 跨模态优化代码部署说明

## 1. 概述

本文档说明如何将工单15的跨模态检索优化代码部署到已运行的 RAGFlow v0.26.0 容器中。

**前提条件**：工单14的 RAGFlow 已正常运行（5容器全healthy），知识库已建好。

---

## 2. 涉及的改动文件

| 文件（源码目录相对路径） | 容器内路径 | 说明 |
|---|---|---|
| `rag/prompts/crossmodal.py` | `/ragflow/rag/prompts/crossmodal.py` | 新增：跨模态优化核心模块 |
| `conf/crossmodal_config.json` | `/ragflow/conf/crossmodal_config.json` | 新增：外部配置文件（含所有可调参数） |
| `api/db/services/dialog_service.py` | `/ragflow/api/db/services/dialog_service.py` | 修改：注入查询增强与提示词扩展（+6行） |

---

## 3. 部署步骤

### 3.1 将文件复制进容器

```bash
cd E:/rag后续工单/ragflow

# 新增模块
docker cp rag/prompts/crossmodal.py docker-ragflow-cpu-1:/ragflow/rag/prompts/crossmodal.py

# 外部配置文件
docker cp conf/crossmodal_config.json docker-ragflow-cpu-1:/ragflow/conf/crossmodal_config.json

# 修改后的 dialog_service
docker cp api/db/services/dialog_service.py docker-ragflow-cpu-1:/ragflow/api/db/services/dialog_service.py
```

### 3.2 验证语法

```bash
docker exec docker-ragflow-cpu-1 python -c "
import ast
ast.parse(open('/ragflow/rag/prompts/crossmodal.py').read())
ast.parse(open('/ragflow/api/db/services/dialog_service.py').read())
print('syntax OK')
"
```

### 3.3 重启 ragflow 使改动生效

```bash
docker restart docker-ragflow-cpu-1
```

### 3.4 确认服务就绪

```bash
curl -s -m 10 http://localhost:9380/api/v1/datasets \
  -H "Authorization: Bearer <你的api_token>" \
  -o /dev/null -w "HTTP %{http_code}\n"
# 返回 HTTP 200 即就绪
```

## 4. 参数调整

优化参数全部在 `conf/crossmodal_config.json` 中，**修改后需重启容器**才能生效。

| 参数 | 默认值 | 说明 |
|---|---|---|
| `enabled` | true | 总开关，false=完全回退原版RAGFlow |
| `query_understanding.enabled` | true | 查询增强开关 |
| `query_understanding.figure_terms` | [...] | 图相关检索词，可根据文档类型定制 |
| `prompt_inject.enabled` | true | 提示词注入开关 |
| `prompt_inject.suffix` | "..." | 跨模态推理引导文本，可按业务场景修改 |
| `fusion.rrf_enabled` | false | RRF多路召回融合（预留，暂不启用） |
| `rerank.enabled` | false | 重排开关（小库关闭省时延，大库可开） |
| `rerank.rerank_id` | "..." | 重排模型实例名（需在RAGFlow内配置） |

---

## 5. 回滚方法

**方式一（配置回滚，秒级）**：

修改 `conf/crossmodal_config.json` 将 `enabled` 改为 `false`，重启容器，所有行为回退到原版RAGFlow。

**方式二（代码回滚）**：

```bash
# 从容器备份恢复原始 dialog_service
docker cp <原始备份> docker-ragflow-cpu-1:/ragflow/api/db/services/dialog_service.py
# 删除新增文件
docker exec docker-ragflow-cpu-1 rm /ragflow/rag/prompts/crossmodal.py
docker exec docker-ragflow-cpu-1 rm /ragflow/conf/crossmodal_config.json
docker restart docker-ragflow-cpu-1
```

## 6. 知识库配置（新文档接入）

新增专利文档的推荐解析配置：

| 配置项 | 推荐值 | 说明 |
|---|---|---|
| 解析方式 | DeepDOC | 支持OCR+版面分析+VLM图描述 |
| 分块方式 | General（naive） | 适合专利文档 |
| image_context_size | 2 | 图片上下2页文本作为VLM描述上下文 |
| raptor | false | 关闭，避免聚类块干扰检索 |
| graphrag | false | 关闭，节省解析时间 |

> ⚠️ `raptor` 和 `graphrag` 需通过直接修改数据库 `parser_config` 字段关闭（RAGFlow UI的PATCH接口白名单限制）：
> ```sql
> UPDATE document SET parser_config = JSON_SET(
>   JSON_SET(parser_config, '$.raptor.use_raptor', false),
>   '$.graphrag.use_graphrag', false
> ) WHERE id='<doc_id>';
> ```
