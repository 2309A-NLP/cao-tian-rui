# RAG系统质量验证检查清单

> 文档版本：v1.0  
> 生成日期：2026-06-05  
> 用途：系统上线前/迭代后的质量验证checklist

---

## 一、功能测试

### 1.1 文档上传与解析

- [ ] PDF文件上传正常，返回成功状态码
- [ ] 纯文本文档（.txt/.md）上传解析正常
- [ ] 大文件（>50MB）上传不超时，有进度提示
- [ ] 重复文件上传有去重/覆盖提示
- [ ] 加密PDF上传返回明确错误提示
- [ ] 乱码/损坏文件上传返回明确错误提示
- [ ] PDF表格提取后数据完整（金额含逗号、日期格式正确）
- [ ] PDF图片文字OCR提取正常
- [ ] 多栏PDF分栏解析顺序正确
- [ ] 批量上传（>10个文件）不丢失不阻塞

### 1.2 文档入库与索引

- [ ] 文档解析后正确写入向量数据库（Milvus/FAISS）
- [ ] chunk数量与预期一致（按分块策略计算）
- [ ] chunk元数据（文件名、页码、公司名）正确携带
- [ ] BM25索引同步构建完成
- [ ] 已有文档重新上传时旧数据正确清理
- [ ] 入库过程中的异常chunk有错误日志

### 1.3 检索功能

- [ ] 基础向量检索返回结果，top_k数量正确
- [ ] BM25检索返回结果，与向量检索结果有交集
- [ ] 多路召回RRF融合后排序合理
- [ ] company_filter过滤生效（A公司query不返回B公司数据）
- [ ] 无结果时返回空列表，不报错
- [ ] Query Rewrite生成的改写query合理
- [ ] HyDE假设性答案检索效果优于直接检索

### 1.4 问答功能

- [ ] 简单事实性问题（如"XX公司2023年营收"）回答正确
- [ ] 多文档对比问题（如"A和B公司毛利率对比"）回答包含双方数据
- [ ] 超出文档范围的问题回答"无法回答"或类似声明
- [ ] 回答中引用的来源页码/段落真实存在
- [ ] 长文档问答不截断（SSE流式输出完整）
- [ ] 多轮对话上下文保持正确
- [ ] system_prompt约束生效，无明显幻觉

### 1.5 历史记录

- [ ] 对话历史正确保存到数据库
- [ ] 历史记录列表按时间倒序显示
- [ ] 点击历史记录可加载完整对话
- [ ] 历史记录分页正常

---

## 二、性能测试

### 2.1 响应时间

- [ ] 简单查询（单文档、事实性）端到端响应 < 5秒
- [ ] 复杂查询（多文档、对比类）端到端响应 < 15秒
- [ ] 文档上传到可检索（入库完成）< 2分钟/10页
- [ ] 首token延迟（SSE首字节时间）< 2秒

### 2.2 并发能力

- [ ] 10并发请求系统不报错
- [ ] 50并发请求系统不崩溃（允许响应变慢）
- [ ] 并发上传不互相阻塞
- [ ] 并发检索不互相污染结果

### 2.3 资源占用

- [ ] 空闲状态内存占用 < 2GB
- [ ] 高负载（10并发）内存占用 < 8GB
- [ ] GPU显存占用在预期范围内（如<4GB for embedding）
- [ ] 无明显内存泄漏（持续运行1小时后内存稳定）

### 2.4 超时与容错

- [ ] LLM调用超时（>60秒）自动中断并返回错误
- [ ] 数据库连接断开后自动重连
- [ ] Redis不可用时系统降级而非崩溃
- [ ] SSE连接断开后服务端资源正确释放

---

## 三、检索质量

### 3.1 召回率验证

- [ ] 标准测试集（50条）召回率 > 80%
- [ ] 精确关键词查询（如"毛利率"）必能在top-10中命中
- [ ] 同义词查询（如"营收"vs"营业收入"）均能召回
- [ ] 数值查询（如"2023年"）时间相关文档优先返回

### 3.2 排序质量

- [ ] 最相关文档排在top-3以内
- [ ] 模板页/样板页不出现在top-10
- [ ] 不同公司文档在company_filter下严格隔离
- [ ] Rerank后排序优于纯向量排序（人工抽检20条）

### 3.3 分块质量

- [ ] chunk边界在语义完整处（不截断句子）
- [ ] chunk包含足够上下文（不丢失表格标题/单位）
- [ ] chunk长度分布合理（中位数300-600字）
- [ ] 重叠区域不导致重复内容过度出现

---

## 四、回答质量

### 4.1 准确性

- [ ] 数值类问题答案与原文一致（如金额、百分比、日期）
- [ ] 逻辑类问题推理过程正确（如"同比增长"计算正确）
- [ ] 引用来源真实存在且内容匹配
- [ ] 多文档对比数据未混淆

### 4.2 完整性

- [ ] 问题涉及多个方面时答案覆盖完整
- [ ] 对比类问题双方数据均包含
- [ ] 列表/表格类信息以结构化格式呈现

### 4.3 安全性（幻觉控制）

- [ ] 文档中不存在的信息不被编造
- [ ] 不确定时明确声明"根据现有资料无法确定"
- [ ] 不生成与原文矛盾的内容
- [ ] NLI幻觉检测通过率 > 90%

### 4.4 格式规范

- [ ] 回答格式统一（段落/列表/表格）
- [ ] 金额保留原始精度（不四舍五入）
- [ ] 百分比保留正确小数位
- [ ] Markdown格式渲染正常

## 五、前端测试

### 5.1 基础交互

- [ ] 页面加载正常，无白屏
- [ ] 输入框可正常输入和发送
- [ ] 消息列表自动滚动到最新消息
- [ ] 发送按钮点击和Enter键发送均正常
- [ ] 发送中有loading状态指示
- [ ] 长文本输入（>1000字）不截断

### 5.2 SSE流式输出

- [ ] 回答逐字/逐句显示（流式效果正常）
- [ ] 流式输出过程中无闪烁/跳动
- [ ] SSE连接断开后有重连提示或自动重连
- [ ] done事件触发后正确关闭连接
- [ ] 多次快速发送不会导致消息错乱

### 5.3 错误处理

- [ ] 网络断开时显示友好提示（非白屏/崩溃）
- [ ] 后端500错误前端有错误提示
- [ ] 超时有明确提示
- [ ] 未登录/权限不足有跳转或提示
- [ ] console中无未捕获的异常（catch不吞错误）
- [ ] 错误信息上报到监控系统

### 5.4 兼容性

- [ ] Chrome浏览器正常运行
- [ ] Firefox浏览器正常运行
- [ ] Edge浏览器正常运行
- [ ] 移动端（手机浏览器）基本可用
- [ ] 不同分辨率下布局不乱

### 5.5 文档管理页面

- [ ] 文档列表正常展示
- [ ] 删除文档确认弹窗正常
- [ ] 文档上传进度条正常
- [ ] 已上传文档状态显示正确（处理中/已就绪/失败）
