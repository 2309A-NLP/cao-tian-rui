# RAG系统评估体系

## 一、检索质量指标

### 1.1 Precision@K（精确率@K）
- **定义**：返回的前K个检索结果中，与问题相关的文档占比
- **公式**：Precision@K = |相关文档 ∩ 前K个结果| / K
- **评估方式**：人工标注或关键词匹配判断相关性
- **K取值**：K=3, K=5, K=10

### 1.2 Recall@K（召回率@K）
- **定义**：前K个检索结果覆盖了多少比例的相关文档
- **公式**：Recall@K = |相关文档 ∩ 前K个结果| / |所有相关文档|
- **评估方式**：预先标注每个问题对应的标准文档集合

### 1.3 MRR（Mean Reciprocal Rank，平均倒数排名）
- **定义**：第一个正确结果排名的倒数的平均值
- **公式**：MRR = (1/|Q|) × Σ(1/rank_i)
- **说明**：MRR越高，说明正确答案越容易被检索到

## 二、答案质量指标

### 2.1 Faithfulness（忠实度）
- **定义**：生成的答案是否忠实于检索到的文档内容，不包含幻觉
- **评估方法**：检查答案中的关键信息是否能在检索来源中找到依据
- **评分标准**：
  - 1分：答案完全基于检索文档
  - 0.5分：部分信息有依据，部分无依据
  - 0分：答案包含大量幻觉信息

### 2.2 Relevancy（相关性）
- **定义**：生成的答案是否准确回答了用户提出的问题
- **评估方法**：比对答案与预期答案的语义匹配度
- **评分标准**：
  - 1分：完全切题回答
  - 0.5分：部分相关
  - 0分：答非所问

### 2.3 Completeness（完整性）
- **定义**：答案是否涵盖了问题所需的所有关键信息点
- **评估方法**：检查答案是否包含预定义的关键信息要素
- **评分标准**：
  - 1分：包含全部关键信息
  - 0.5分：包含部分关键信息
  - 0分：缺失关键信息

## 三、系统性能指标

### 3.1 检索延迟（Retrieval Latency）
- **定义**：从发送查询请求到获取检索结果的时间
- **衡量**：首字节时间（TTFB）、检索完成时间
- **目标**：P95 < 2秒

### 3.2 LLM延迟（LLM Latency）
- **定义**：从获取检索结果到生成完整答案的时间
- **衡量**：首token延迟、完整响应时间
- **目标**：P95 < 5秒

### 3.3 端到端延迟（End-to-End Latency）
- **定义**：从用户提问到获得完整答案的总时间
- **目标**：P95 < 8秒
