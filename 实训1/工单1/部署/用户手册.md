# RAG 智能问答系统 — 用户手册

## 1. 快速开始

### 1.1 系统要求

- Python 3.10 或以上版本
- Milvus 2.x 向量数据库（默认地址 `127.0.0.1:19530`）
- MySQL 8.x 数据库（默认地址 `127.0.0.1:3307`）
- 可联网（需调用 DeepSeek API 与下载嵌入模型）

### 1.2 安装步骤

```bash
# 1. 进入项目目录
cd 任务 1

# 2. 安装 Python 依赖
pip install -r requirements.txt

# 3. 确认 Milvus 已启动
# 默认连接 127.0.0.1:19530

# 4. 确认 MySQL 已启动
# 默认连接 127.0.0.1:3307，数据库名 rag_system

# 5. 修改配置文件
# 编辑 config.json，填入 DeepSeek API Key 等信息

# 6. 启动系统（任选一种模式）
python main.py --mode cli          # 命令行模式
streamlit run frontend/streamlit_app.py   # Streamlit 界面
uvicorn api.main:app --port 8000   # API 服务模式
```

### 1.3 配置说明

首次使用前，请编辑项目根目录下的 `config.json`：

- **DeepSeek API Key**：在 [DeepSeek 开放平台](https://platform.deepseek.com) 获取，填入 `llm.api_key`
- **数据库连接**：根据实际环境修改 `mysql` 和 `milvus` 的地址与端口
- **其他参数**：`rag.chunk_size`（分块大小）、`rag.top_k`（检索数量）等可根据需要调整

## 2. 用户注册与登录

### 2.1 注册账号

1. 打开系统界面（Streamlit 或 Web SPA）
2. 点击「注册」按钮
3. 输入用户名（3-50 个字符）和密码（6 位以上）
4. 点击「确认注册」，提示注册成功后即可登录

> 注意：用户名不可重复，如提示"用户名已存在"请更换用户名。

### 2.2 登录系统

1. 在登录页面输入已注册的用户名和密码
2. 点击「登录」
3. 登录成功后进入系统主界面

登录后系统自动保持会话状态，Token 有效期默认 24 小时。

## 3. 知识库管理

### 3.1 上传 PDF 文档

1. 在左侧导航栏选择「知识库管理」
2. 点击「上传文档」按钮
3. 选择要上传的 PDF 文件（单文件最大 20MB）
4. 输入知识库名称（如"技术文档"），或选择已有知识库追加上传
5. 点击「开始上传」
6. 等待系统处理完成（解析 → 分块 → 向量化 → 入库）

处理完成后，系统会显示：
- 分块数量：文档被切分为多少个文本块
- 知识库状态：可开始问答

> 提示：处理时间取决于文档大小，通常几十页的 PDF 需要 30 秒至 2 分钟。

### 3.2 查看知识库列表

在知识库管理页面可以看到所有已创建的知识库，包括：
- 知识库名称
- 包含的文档数量
- 总文本块数量
- 创建时间

### 3.3 删除知识库

1. 在知识库列表中找到要删除的知识库
2. 点击「删除」按钮
3. 确认删除

> 注意：删除知识库会同时删除该知识库下的所有向量数据，此操作不可恢复。

## 4. 智能问答

### 4.1 提问方式

1. 在主界面的输入框中输入问题
2. 选择查询模式（见 4.2）
3. 选择要使用的知识库（如选择"rag"模式）
4. 点击「发送」或按回车键
5. 等待系统返回回答

### 4.2 查询模式说明

系统支持三种查询模式，可根据需求选择：

#### RAG 模式（推荐）

系统从知识库中检索相关文档片段，结合检索结果让大模型生成回答。

- **适用场景**：针对已有文档的精准提问
- **优势**：回答有据可查，可显示引用来源
- **示例**：上传了某产品手册后，提问"如何重置设备？"

#### Direct 模式

直接向大模型提问，不检索知识库，完全依赖模型自身知识。

- **适用场景**：通用知识问答，与文档无关的问题
- **优势**：响应速度快，无需上传文档
- **示例**："Python 中如何读取 JSON 文件？"

#### Both 模式

同时返回 RAG 模式和 Direct 模式的回答，方便对比两种结果。

- **适用场景**：需要比较知识库回答与通用回答的差异
- **优势**：一次提问获得两种视角的回答

### 4.3 流式输出

在支持 SSE（Server-Sent Events）的界面中，回答会以打字机效果逐字显示，提供更好的交互体验。

### 4.4 查看引用来源

在 RAG 模式下，回答下方会显示引用来源列表，包括：
- 来源页码
- 匹配的文本片段
- 相似度分数

点击来源片段可查看完整的上下文内容。

## 5. 历史记录管理

### 5.1 查看历史记录

1. 在左侧导航栏选择「历史记录」
2. 系统按时间倒序显示所有问答记录
3. 每条记录包含：问题、回答、使用的模式、知识库名称、时间

### 5.2 查看历史详情

点击某条历史记录，可展开查看完整的问答内容，包括：
- 完整问题文本
- 完整回答文本
- 引用来源（RAG 模式）
- 查询参数

### 5.3 删除历史记录

- **删除单条**：在某条记录上点击「删除」按钮
- **清空全部**：点击页面顶部的「清空历史」按钮

> 注意：清空历史操作不可恢复，请谨慎操作。

## 6. 常见问题（FAQ）

### Q1: 上传 PDF 后提示"解析失败"怎么办？

**A:** 请检查以下几点：
- 确认文件格式为 PDF（非图片 PDF 或扫描件暂不支持）
- 确认文件未损坏（可正常用 PDF 阅读器打开）
- 确认文件大小不超过 20MB
- 如果是加密 PDF，请先解除密码保护

### Q2: 问答时提示"未找到相关内容"？

**A:** 可能原因：
- 未选择正确的知识库，或该知识库中没有文档
- 问题与文档内容差异较大，相似度未达到阈值
- 尝试换一种表述方式提问
- 可在 `config.json` 中降低 `rag.similarity_threshold` 的值

### Q3: 回答质量不高怎么办？

**A:** 可以尝试以下优化：
- 提高文档质量，确保 PDF 内容清晰、结构化
- 调整 `rag.top_k`（增加检索数量，默认 5）
- 调整 `rag.chunk_size`（分块大小影响检索精度）
- 使用更具体、明确的问题表述
- 确认文档内容与问题相关

### Q4: 系统响应很慢怎么办？

**A:** 可能原因及解决方案：
- **首次加载慢**：BGE-M3 模型首次加载需要时间，后续会快很多
- **文档处理慢**：大文件分块和向量化需要时间，属于正常现象
- **问答响应慢**：可能是 DeepSeek API 响应慢，检查网络连接
- **检索慢**：Milvus 数据量过大时可考虑优化索引参数

### Q5: 如何更换大模型？

**A:** 修改 `config.json` 中的 `llm` 配置段：
- 修改 `provider` 为新的模型提供商
- 修改 `api_key` 为新的 API Key
- 修改 `model` 为新的模型名称
- 修改 `base_url` 为新的 API 地址

### Q6: 忘记密码怎么办？

**A:** 目前系统不支持自助找回密码。请联系系统管理员，通过数据库直接重置密码哈希值。

### Q7: 支持哪些语言的文档？

**A:** BGE-M3 嵌入模型支持中英文等多种语言。系统在中文和英文文档上表现最佳，其他语言的检索精度可能有所下降。

### Q8: 可以同时上传多个 PDF 吗？

**A:** 可以将多个 PDF 上传到同一个知识库名称下，系统会将所有文档的文本块合并存储。建议将相关主题的文档放在同一知识库中，便于检索。

### Q9: 如何备份数据？

**A:** 需要备份以下内容：
- **MySQL 数据库**：包含用户信息和聊天历史
- **Milvus 数据**：包含向量索引数据
- **config.json**：系统配置文件
- **原始 PDF 文件**：建议保留原始文档

### Q10: 如何在生产环境部署？

**A:** 推荐使用 FastAPI + SPA 模式：
1. 使用 Gunicorn + Uvicorn workers 运行后端
2. 使用 Nginx 反向代理
3. 配置 HTTPS 证书
4. 将 Milvus 和 MySQL 部署为独立服务
5. 设置合适的 `config.json` 参数（关闭 debug、调整 token 过期时间等）
