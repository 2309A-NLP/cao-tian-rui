# 金融文档 RAG 系统 · 架构设计文档

> 项目：基于招股说明书 / 年报的金融文档智能问答（RAG）系统
> 文档版本：v1.0 · 2026-06-12

---

## 一、系统概述

本系统是一个面向金融文档的检索增强生成（RAG）问答系统。知识库包含科创板招股说明书与银行/保险/券商年度报告共 11 份文档、约 18,443 个文本块。用户输入自然语言问题，系统检索相关文档片段并由大模型生成带页码引用的答案。

**核心设计目标**
- 检索准确率 > 90%、召回率 > 95%
- 端到端响应 < 3 秒
- 支持向量 / 全文 / 混合三种检索模式可切换

---

## 二、技术栈

| 层 | 组件 | 说明 |
|---|---|---|
| 嵌入模型 | BGE-M3 (1024 维) | transformers 直接加载，GPU 推理 |
| 向量库 | Milvus 2.3+ | IVF_FLAT 索引，内积(IP)度量 |
| 全文检索 | rank-bm25 + jieba | 中文分词 + BM25 打分 |
| 大模型 | DeepSeek-Chat | OpenAI 兼容接口，可切 SiliconFlow |
| 多模态 | Qwen3-VL-Plus | 表格/图表页解析为 markdown |
| 后端 | FastAPI + Uvicorn | REST API，端口 8010 |
| 会话/存储 | Redis + MySQL | 会话记忆 + 历史记录 |
| 评估 | 自研 eval + RAGAS | Hit@k/MRR/Recall + LLM 裁判 |

## 五、检索流程详解（在线链路）

1. **查询接收**：`POST /api/ask`，参数含 query、mode(rag/direct)、retrieval_mode(vector/fulltext/hybrid)。
2. **查询改写**（可选）：仅当问题含代词（它/该/上述等）时调用 LLM 补全为独立问题，否则跳过以省时。
3. **多路检索**：
   - 向量：BGE-M3 编码 query → Milvus ANN 检索
   - 全文：jieba 分词 → BM25 打分
   - 二者按 RRF（Reciprocal Rank Fusion）融合
4. **重排**：关键词命中重排（保证含关键词的块靠前）+ 自适应重排（按 top1 置信度决定是否上交叉编码器）。
5. **上下文组装**：去重 → 截取 top_k → 取前 8 块构建上下文（控制 prefill，保障 <3s）。
6. **生成**：拼接 system_prompt + 上下文 + 历史 + 问题，调 DeepSeek 生成，要求引用页码。

## 六、数据流与索引一致性（关键设计点）

- **chunk 全局唯一编号**：向量检索（Milvus）与 BM25（all_chunks.json）需共用同一套 `chunk_id`，RRF 才能正确融合。这是 hybrid 模式正确性的前提。
- **字段类型加权**：每个 chunk 带 field_type（title/abstract/table/body），向量检索按类型加权（title 1.6×、table 1.2× 等）。
- **公司/文件名标记**：chunk 文本前缀加【文件】/【公司】标记，用于多文档路由过滤。

## 七、配置要点（config.json）

| 配置项 | 当前值 | 含义 |
|---|---|---|
| retrieval_mode | fulltext | 默认检索模式 |
| top_k | 15 | 最终返回块数 |
| chunk_size / overlap | 800 / 150 | 分块大小与重叠 |
| bm25_alpha | 0.4 | RRF 中 BM25 权重 |
| embedding_model_type | bge-m3 | 嵌入模型 |
| milvus_collection | doc_chunks | 向量集合名 |
