# 金融文档 RAG 系统 · 部署文档

> 文档版本：v1.0 · 2026-06-12
> 适用环境：Windows（gpu_env 已验证）/ Linux 均可

---

## 一、环境依赖

### 1. 硬件
- GPU：NVIDIA 显卡（已验证 RTX 5060 Laptop，CUDA）。无 GPU 可用 CPU，但嵌入与生成会变慢。
- 内存：≥ 16 GB（BGE-M3 + Milvus + BM25 索引常驻）。
- 磁盘：≥ 10 GB（模型 + 向量库 + 中间产物）。

### 2. 基础软件
- Python 3.10+
- Milvus 2.3+（向量库，需单独部署，见第三节）
- Redis 5+（会话记忆，可选）
- MySQL 5.7+/8（历史记录，可选，端口 3307）

### 3. 模型文件（需提前下载到本地）
| 模型 | 配置项 | 示例路径 |
|---|---|---|
| BGE-M3 嵌入模型 | embedding_model_path | `F:\...\bge-m3` |
| BGE-Reranker（可选） | reranker_model_path | 留空则不启用 |

> 模型路径在 `config.json` 中配置，支持 Windows 与 WSL 路径自动检测。

## 二、Python 依赖安装

```bash
# 建议使用 conda 虚拟环境（项目使用 gpu_env）
conda activate gpu_env

cd "项目根目录"
pip install -r requirements.txt
```

`requirements.txt` 核心依赖：
```
streamlit>=1.28.0      # 前端（可选）

pymysql>=1.1.0         # MySQL
PyMuPDF>=1.23.0        # PDF 解析（fitz）
fastapi>=0.104.0       # 后端框架
uvicorn[standard]      # ASGI 服务器
redis>=5.0.0           # 会话管理
```

> 注意：torch 需根据本机 CUDA 版本从官方源安装对应版本，勿直接 pip 默认版。
> 可选：评估用 RAGAS 需额外 `pip install ragas datasets langchain-openai`。

## 三、Milvus 部署

```bash
# 使用 Docker Compose（官方推荐，单机版）
# 1. 下载 milvus-standalone-docker-compose.yml
# 2. 启动
docker compose up -d

# 默认端口 19530，与 config.json 的 milvus_port 一致
```
确认 `config.json`：
```json
"milvus_host": "127.0.0.1",
"milvus_port": 19530,
"milvus_collection": "doc_chunks"
```

## 五、构建知识库索引（首次部署必做）

```bash
# 把待索引的 PDF 放入 knowledge_base/ 目录

# 方式一：混合策略（招股书，含 Qwen3-VL 多模态，需 qwen3_api_key）
python run_hybrid_reindex.py
#   等效于: python backend/main.py --reindex --hybrid --config config.json

# 方式二：增量索引单个文件
python backend/main.py --index "knowledge_base/xxx.pdf"

# 索引完成后中间产物落地 output/chunks/all_chunks.json
```

> ⚠️ 注意：`--reindex` 会清空 Milvus 集合后重建。若库内已有不在 knowledge_base/ 的文档，重建会丢失它们，执行前请确认。
> 统一索引重建（向量+BM25 同源）：`python backend/rebuild_unified_index.py`

## 八、常见问题排查

| 现象 | 原因 | 解决 |
|---|---|---|
| `WinError 10061 目标计算机积极拒绝` | API 服务未启动 | 先 `python run_api.py`，等 `Uvicorn running` |
| BM25 索引未构建 | 缺 jieba/rank-bm25 或 all_chunks.json 不存在 | 安装依赖 + 先建索引 |
| Milvus 连接失败 | Milvus 容器未启动 | `docker compose up -d` 检查 19530 端口 |
| 嵌入模型加载失败 | embedding_model_path 路径错 | 核对 config.json 中模型路径 |
| 检索为空（vector/hybrid） | 年报仅在 BM25，未进向量库 | 测年报用 fulltext，或先做统一索引重建 |
| RAGAS 报 Invalid n value | DeepSeek 仅支持 n=1 | 已在 eval_quick 设 strictness=1 修复 |
| 端到端 >3s | LLM 长答案生成慢 | 启用流式输出 / 限 max_tokens |

## 九、目录结构

```
项目根/
├── config.json              # 全局配置
├── run_api.py               # 后端启动入口（端口 8010）
├── run_hybrid_reindex.py    # 一键混合索引
├── requirements.txt
├── knowledge_base/          # 待索引 PDF
├── api/api.py               # FastAPI 路由
├── backend/                 # 核心模块
│   ├── rag_engine.py        # RAG 对话核心
│   ├── retrieval_strategy.py# 检索策略
│   ├── vector_store.py      # Milvus + BM25
│   ├── embedding_provider.py# 嵌入模型
│   ├── hybrid_processor.py  # 多模态 PDF 处理
│   ├── llm_provider.py      # LLM 抽象
│   ├── eval_quick.py        # 评估框架
│   ├── eval_compare.py      # 跨运行对比
│   ├── rebuild_unified_index.py  # 统一索引重建
│   └── ccf_testset.json     # 年报测试集
└── output/                  # 中间产物
    ├── chunks/all_chunks.json
    ├── hybrid_vl_output/    # VL 解析中间产物
    └── eval_history/        # 评估结果归档
```
