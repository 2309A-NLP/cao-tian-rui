## 3. LightRAG 核心原理

### 3.1 与标准 RAG 的区别

| 对比维度 | 标准 RAG | LightRAG |
|---------|---------|---------|
| 知识表示 | 文本块（chunk）列表 | 实体-关系知识图谱 |
| 检索单元 | 相似度最高的K个chunk | 图谱节点+关联边+关联chunk |
| 上下文构建 | 拼接Top-K chunk | 实体邻居+关系描述+原文chunk三层融合 |
| 多跳推理 | 依赖LLM跨chunk理解 | 图遍历天然支持多跳 |
| 跨文档关联 | 依赖向量相似度 | 共享实体节点自动关联 |
| 构建成本 | 低（分块+向量化） | 高（LLM抽取实体关系） |

### 3.2 双层检索架构

```
用户查询
    │
    ▼
┌──────────────────────────────────────────────┐
│             关键词抽取（LLM）                   │
│  query → ["武汉力源信息", "发行股数", "比例"]    │
└─────────────────────┬────────────────────────┘
                      │
          ┌───────────┴────────────┐
          ▼                        ▼
┌─────────────────┐      ┌──────────────────────┐
│  Local 检索      │      │  Global 检索           │
│ 基于实体向量相似度│      │ 基于关系向量相似度      │
│ 找邻居实体+关系   │      │ 找全局关联关系         │
│ (深度细节信息)    │      │ (宏观结构信息)         │
└────────┬────────┘      └────────────┬─────────┘
         │                            │
         └────────────┬───────────────┘
                      ▼
          ┌───────────────────────┐
          │  上下文融合              │
          │ 实体描述 + 关系描述      │
          │ + 关联chunk原文          │
          │ → 截断到token预算        │
          └───────────┬───────────┘
                      │
                      ▼
          ┌───────────────────────┐
          │   LLM 生成回答          │
          └───────────────────────┘
```

## 5. 检索模式设计

LightRAG 支持 5 种检索模式，系统默认使用 `hybrid`：

| 模式 | 说明 | 适用场景 |
|------|------|---------|
| `local` | 仅实体本地邻域检索（深度细节） | 特定实体的详细属性查询 |
| `global` | 仅关系全局检索（宏观结构） | 跨实体关联、宏观趋势查询 |
| `hybrid` | local + global 双路融合 | 通用查询（默认，推荐） |
| `naive` | 仅 chunk 向量相似度（无图谱） | 对照组，等价于简单RAG |
| `mix` | hybrid + naive 三路融合 | 最全面覆盖，成本最高 |

### 模式性能对比（16题评估集）

| 模式 | 通过率 | ctx_recall | 均延迟 |
|------|--------|----------|--------|
| hybrid | 93.8% | 87.0% | 295ms |
| mix | 87.5% | 88.5% | 3423ms |
| naive | 87.5% | - | - |

## 6. LLM 故障转移链

### 6.1 设计目标

DeepSeek 官方 API 存在偶发性限速（429）和超时，通过指数退避+备用链路保证图谱构建的稳定性。

### 6.2 故障转移策略

```
primary: DeepSeek Official (api.deepseek.com)
    ↓ 失败（429/超时/网络错误）
    ↓ 等待 2^n 秒（最大 60s）重试 3 次
    ↓ 仍失败
fallback: SiliconFlow (api.siliconflow.cn)
          model: deepseek-ai/DeepSeek-V3
    ↓ 失败
    ↓ 重试 2 次
    ↓ 仍失败 → 抛出异常，停止当前批次
```

### 6.3 关键参数

| 参数 | 值 | 说明 |
|------|------|------|
| primary_model | deepseek-chat | DeepSeek官方最新模型 |
| fallback_model | deepseek-ai/DeepSeek-V3 | SiliconFlow托管版本 |
| max_retry | 3 | 每个节点最大重试次数 |
| backoff_base | 2 | 指数退避基数（秒） |
| max_backoff | 60 | 最大等待时间（秒） |
| timeout | 180 | 单次调用超时（秒） |
| max_async | 4 | 并发请求数 |

```
┌─────────────────────────────────────┐

```

```
    │
```

## 10. 配置说明

### 10.1 LightRAG 关键参数

| 参数 | 值 | 说明 |
|------|------|------|
| working_dir | ./lightrag_storage_prospectus | 图谱存储目录 |
| embedding_dim | 1024 | BGE-M3向量维度 |
| embedding_device | cuda | GPU加速 |
| max_async | 4 | LLM并发数（限速友好）|
| timeout | 180 | LLM调用超时（秒）|
| enable_rerank | False | 关闭（未配置rerank模型）|

### 10.2 评估脚本参数

```bash
# LightRAG评估（含RAGAS）
python eval_lightrag.py \
    --modes hybrid \           # 评估模式：hybrid/mix/naive/local/global
    --ragas \                  # 开启RAGAS评分（需DeepSeek API key）
    --out output \             # 输出目录
    --limit 3                  # 仅测前N题（冒烟测试，省API费）

# RAG基线评估（含RAGAS）
python eval_quick.py --ragas
```
