## 第一步：启动后端服务（两个窗口）

### 窗口 A — 启动 Neo4j
```powershell
docker start neo4j
# 等待约 10s，访问 http://localhost:7474 能看到登录页表示成功
# 账号 neo4j / 密码 medical123
```

### 窗口 B — 启动 API 服务
```powershell
cd "F:\kimi  project\医疗agent1\02-健康咨询"
.venv\Scripts\python -m uvicorn src.app:app --host 0.0.0.0 --port 8012
```

看到以下输出表示启动成功：
```
INFO:     Application startup complete.
INFO:     Uvicorn running on http://0.0.0.0:8012
```

## 第四步：跑 pytest 自动化测试

**另开一个 PowerShell 窗口**（保持窗口B的服务在跑）：

```powershell
cd "F:\kimi  project\医疗agent1\02-健康咨询"
.venv\Scripts\python -m pytest tests/ -v
```

共 **20 个测试用例**（10 主题 + 10 变体），预期全部通过。

> 测试耗时约 **3-5 分钟**（每题约 5-10s，含 1s 防限流间隔）

### 如果测试失败

```powershell
# 先跑快速冒烟（4题，约30s）
.venv\Scripts\python scripts/quick_test.py
```

- 全部 PASS → pytest 失败可能是 assert 关键词不匹配，看具体报错
- 有 ERR → 服务或 Neo4j 连接有问题，先检查窗口 B 是否报错

## 常见问题速查

| 现象 | 原因 | 解决 |
|------|------|------|
| `Connection refused` 或页面打不开 | 服务没起 | 检查窗口 B，重跑 uvicorn 命令 |
| 图谱统计全是 0 | Neo4j 容器未启动或数据未导入 | `docker start neo4j`，等10s再刷 |
| 答案里没有具体数据，只有模糊回答 | Neo4j 查询无命中 | 正常兜底行为，答案末尾会有说明 |
| Neo4j 浏览器打开后崩溃 | 未登录时跳转带参数链接 | 先打开 `http://localhost:7474` 登录，再用聊天页的链接 |
| pytest 某题 FAIL | 关键词未命中 | 看 `-v` 详细输出，reply 内容对不上预期关键词 |
| 响应很慢（5-10s） | 两次 LLM 调用，正常 | 不是 Bug，Neo4j 检索本身 < 100ms |
