# 工单12 · 健康咨询 · 启动说明

## 前置条件

| 依赖 | 状态 | 说明 |
|------|------|------|
| Neo4j Docker 容器 | 需运行 | `docker start neo4j` |
| 医疗知识图谱数据 | 需导入 | 见步骤3（已导入则跳过） |
| 硅基流动 API Key | 需配置 | `.env` 文件 |
| Python venv | 需创建 | 见步骤1 |

---

## 步骤1：创建虚拟环境并安装依赖

```powershell
cd "F:\kimi  project\医疗agent1\02-健康咨询"
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
```

---

## 步骤2：配置环境变量

```powershell
copy .env.example .env
# 用编辑器打开 .env，填入：
#   SILICONFLOW_API_KEY=sk-xxx
#   NEO4J_PASSWORD=medical123   （与 docker 容器设置一致）
```

---

## 步骤3：导入知识图谱（已导入则跳过）

```powershell
# 确认 Neo4j 容器在运行
docker start neo4j

# 导入 medical.json（约需 3-5 分钟）
.venv\Scripts\python scripts/import_graph.py

# 快速验证（只导前 100 条）
.venv\Scripts\python scripts/import_graph.py --limit 100
```

导入完成后验证：打开 http://localhost:7474，运行 `MATCH (n) RETURN count(n)` 应返回 ~3万+节点。

---

## 步骤4：启动 API 服务

```powershell
cd "F:\kimi  project\医疗agent1\02-健康咨询"
.venv\Scripts\python -m uvicorn src.app:app --port 8012 --reload
```

服务启动后访问：
- 聊天界面：http://localhost:8012
- API 文档：http://localhost:8012/docs
- 健康检查：http://localhost:8012/health
- 图谱统计：http://localhost:8012/stats

## 踩坑速查

| 症状 | 原因 | 解决 |
|------|------|------|
| 图谱查不到数据 | medical.json 编码问题导入成乱码 | `MATCH (n) DETACH DELETE n` 清库后重导 |
| Windows `print` 乱码 | GBK 终端 | 脚本顶部已加 `reconfigure(encoding='utf-8')` |
| `NEO4J_PASSWORD 未配置` 报错 | `.env` 未设置 | 复制 `.env.example` 并填值 |
| mem0 初始化失败 | chromadb 未安装 | 正常现象，记忆功能禁用，主功能不受影响 |
