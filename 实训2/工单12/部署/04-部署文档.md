## 三、首次部署步骤

### Step 1：克隆/解压项目

确认目录结构：
```
F:\kimi  project\医疗agent1\02-健康咨询\
├── src\
├── tests\
├── scripts\
├── data\medical.json   ← 必须存在（~50MB）
├── .env.example
└── requirements.txt
```

### Step 2：创建 Python 虚拟环境并安装依赖

```powershell
cd "F:\kimi  project\医疗agent1\02-健康咨询"
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
```

`requirements.txt` 核心依赖：
```
fastapi>=0.111
uvicorn[standard]>=0.30
neo4j>=5.14
openai>=1.30          # 兼容硅基流动 OpenAI 协议
pydantic>=2.0
python-dotenv>=1.0
```

### Step 3：配置 `.env`

复制 `.env.example` 为 `.env`，填写实际值：

```ini
# Neo4j
NEO4J_URI=bolt://localhost:7687
NEO4J_USER=neo4j
NEO4J_PASSWORD=your_password_here

# 硅基流动 LLM
LLM_BASE_URL=https://api.siliconflow.cn/v1
LLM_API_KEY=sk-xxxxxxxxxxxxxxxx
LLM_MODEL=Qwen/Qwen2.5-72B-Instruct

# 服务
PORT=8012
API_KEY=dev-key-12345          # 内部鉴权，前端 X-API-Key 头需与此一致

# CORS（多值用逗号分隔）
CORS_ORIGINS=http://localhost:8012,null,http://localhost:8000,http://127.0.0.1:8000
```

> `null` 用于支持本地 `file://` 协议打开的主框架 iframe 嵌入。

### Step 4：启动 Neo4j

```powershell
# 首次：创建容器
docker run -d \
  --name neo4j \
  -p 7474:7474 -p 7687:7687 \
  -v F:/neo4j/data:/data \
  -e NEO4J_AUTH=neo4j/your_password_here \
  neo4j:5.14-community

# 后续：直接启动
docker start neo4j
```

确认启动：浏览器访问 `http://localhost:7474`，能登录即可。

### Step 5：导入医疗图谱数据

**首次部署必须执行**，约 5-10 分钟：

```powershell
.venv\Scripts\python scripts/import_graph.py
```

导入完成后验证节点数：
```cypher
# Neo4j Browser 中执行
MATCH (n) RETURN labels(n), count(n) ORDER BY count(n) DESC
```

预期结果：
```
Disease     6720
Symptom     5936
Drug        1124
Food        ...
Department  ...
```

> `import_graph.py` 使用 `MERGE`（幂等），重复执行不会创建重复节点。

### Step 6：启动服务

```powershell
cd "F:\kimi  project\医疗agent1\02-健康咨询"
.venv\Scripts\python -m uvicorn src.app:app --host 0.0.0.0 --port 8012
```

验证启动：
```powershell
# 健康检查
curl http://localhost:8012/health

# 图谱统计
curl http://localhost:8012/stats
```

正常输出：
```json
{"status": "ok", "neo4j": "connected", "disease_count": 6720}
```

### Step 7：验证前端

1. 直接打开：浏览器访问 `http://localhost:8012/`（或直接打开 `chat.html`）
2. 主框架嵌入：访问 `http://localhost:8000/`（门户需先用 `python -m http.server 8000` 启动），点击"健康咨询"菜单项

## 四、日常运维

### 启动顺序（每次开机）

```powershell
# 1. 启动 Neo4j
docker start neo4j

# 2. 启动健康咨询服务（新开一个 PowerShell 窗口）

```

### 停止服务

```powershell
# 停止 uvicorn：Ctrl+C
# 停止 Neo4j
docker stop neo4j
```

### 查看实时日志

uvicorn 默认输出到终端，包含每条请求的状态码和耗时。如需持久化：

```powershell
.venv\Scripts\python -m uvicorn src.app:app --port 8012 2>&1 | Tee-Object -FilePath logs\app.log -Append
```

## 五、故障排查

### 故障1：服务启动报 `ConnectionRefusedError: [WinError 10061]`

**含义**：无法连接 Neo4j（bolt://localhost:7687）。

**排查**：
```powershell
docker ps | findstr neo4j   # 确认容器在运行
docker logs neo4j           # 看 Neo4j 自身启动日志
```

**解法**：`docker start neo4j`，等 10 秒后重试服务启动。

---

### 故障2：前端 iframe 显示白板/空白

**现象**：主框架点击"健康咨询"，右侧 iframe 区域全白。

**排查步骤**：
1. 浏览器 F12 → Console，看是否有 CORS 报错
2. 直接访问 `http://localhost:8012/` 是否正常
3. 确认 `.env` 的 `CORS_ORIGINS` 包含 `null`（用于 file:// 协议）

**解法**：在 `.env` 中追加 `null` 到 `CORS_ORIGINS`，重启服务。

---

### 故障3：输入问题后无响应，主框架底部聊天栏拦截输入

**现象**：在健康咨询 iframe 内打字，消息被主框架底部 chat bar 捕获，显示"模块尚未接入"。

**根因**：主框架 `MODULE_PLACEHOLDER` 配置包含了 `consult`，全局键盘监听拦截了 iframe 内输入。

**解法**：检查 `index.html` 的 `MODULE_PLACEHOLDER` 对象，确认不包含 `consult` 键。同时确认切换到健康咨询 tab 时执行了 `.chat-input-bar { display: none }`。

---

### 故障4：图谱查询返回空，回答质量差

**现象**：问"高血压有哪些症状？"，回答"未找到相关图谱数据"。

**排查**：
```cypher
# Neo4j Browser
MATCH (d:Disease {name: "高血压"}) RETURN d
```

**解法**：
- 若节点不存在 → 疾病名拼写问题（图谱用"高血压"，用户可能输入"高血壓"繁体）
- 若节点存在但无关系 → 检查导入是否完整，重跑 `import_graph.py`

---

### 故障5：LLM API 返回 401 / 403

**含义**：API Key 无效或 Qwen2.5-72B 无权限。

**解法**：
1. 登录硅基流动控制台，确认 API Key 有效
2. 确认账户余额充足
3. `.env` 中 `LLM_API_KEY` 是否正确（无多余空格）

---

### 故障6：PowerShell 执行命令报 `→ : The term '→' is not recognized`

**原因**：文档中 `→` 是视觉分隔符，不是 shell 操作符。

**解法**：将 `→` 前后的内容分成两行单独执行：
```powershell
# 错误（不能这样）：cd "path" → python ...
# 正确（分两行）：
cd "F:\kimi  project\医疗agent1\02-健康咨询"
.venv\Scripts\python -m uvicorn src.app:app --port 8012
```

## 六、配置参数速查

| 参数 | 位置 | 说明 | 默认值 |
|------|------|------|-------|
| `NEO4J_URI` | `.env` | Neo4j bolt 连接地址 | bolt://localhost:7687 |
| `NEO4J_PASSWORD` | `.env` | Neo4j 密码 | — |
