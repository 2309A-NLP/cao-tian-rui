## 一、需求概述

### 1.1 业务背景
健康咨询是患者获取疾病知识、用药指导、护理建议的重要渠道。传统的搜索引擎方式信息质量参差不齐，患者难以获得准确、可信赖的医学知识。本模块通过 **医疗知识图谱 + 大模型生成** 的方式，为患者提供精准、可解释的健康咨询服务。

### 1.2 目标用户
- **主要用户**: 有健康问题咨询需求的患者及家属
- **用户特征**: 非医学专业背景，需要通俗易懂的解释
- **使用场景**: 症状自查、用药咨询、疾病了解、护理指导

### 2.2 知识图谱结构

基于 `medical.json` 构建的知识图谱包含以下核心实体和关系:

```
实体类型 (Node Labels):
├── Disease (疾病)        如: 百日咳、流感、肺炎
├── Symptom (症状)        如: 咳嗽、发热、痉挛性咳嗽
├── Pathogen (病原体)     如: 百日咳杆菌、流感病毒
├── Drug (药物)           如: 红霉素、阿奇霉素
├── BodyPart (身体部位)   如: 支气管、肺部
├── Department (科室)     如: 儿科、呼吸内科
├── Transmission (传播途径) 如: 呼吸道飞沫传播
├── Complication (并发症) 如: 支气管肺炎、肺不张
├── TCM_Pattern (中医证型) 如: 痉咳期、初咳期
└── Precaution (预防措施) 如: 隔离、疫苗接种

关系类型 (Relationships):
├── (Disease)-[:HAS_SYMPTOM]->(Symptom)           疾病有症状
├── (Disease)-[:CAUSED_BY]->(Pathogen)           疾病由病原体导致
├── (Disease)-[:TRANSMITTED_BY]->(Transmission)  疾病通过途径传播
├── (Disease)-[:TREATED_BY]->(Drug)              疾病用药物治疗
├── (Disease)-[:HAS_COMPLICATION]->(Complication) 疾病有并发症
├── (Disease)-[:BELONGS_TO]->(Department)        疾病属于科室
├── (Drug)-[:ADMINISTERED_TO]->(BodyPart)        药物作用于部位
├── (Disease)-[:HAS_TCM_PATTERN]->(TCM_Pattern)  疾病有中医证型
├── (TCM_Pattern)-[:TREATED_BY_TCM]->(Drug)      证型用中药治疗
└── (Disease)-[:REQUIRES_PRECAUTION]->(Precaution) 疾病需要预防
```

## 三、Agent 交互设计

### 3.1 对话示例 - 百日咳全流程咨询

**Q1: 病原体识别**
```
用户: 百日咳的致病病原体是什么?

Agent 思考过程:
1. 实体识别: 疾病=百日咳
2. 意图识别: 查询病原体
3. Cypher 查询: MATCH (d:Disease {name:'百日咳'})-[:CAUSED_BY]->(p:Pathogen) RETURN p.name
4. 图谱结果: 百日咳杆菌（鲍特菌属中的百日咳鲍特菌）
5. LLM 生成答案: '百日咳的致病病原体是百日咳杆菌...'
```

**Q2: 传播途径**
```
用户: 百日咳主要通过什么途径传播?
Cypher: MATCH (d:Disease {name:'百日咳'})-[:TRANSMITTED_BY]->(t:Transmission) RETURN t.name
答案: 呼吸道飞沫传播
```

**Q3: 典型症状**
```
用户: 百日咳最具特征性的临床表现是什么?
Cypher: MATCH (d:Disease {name:'百日咳'})-[:HAS_SYMPTOM]->(s:Symptom) RETURN s.name
答案: 阵发性痉挛性咳嗽伴鸡鸣样吸气吼声
```

**Q4: 实验室诊断**
```
用户: 百日咳患者的血常规检查会呈现什么特征?
答案: 外周血白细胞计数明显增高且淋巴细胞为主
```

**Q5: 治疗药物**
```
用户: 百日咳西医治疗首选的抗生素是什么?
Cypher: MATCH (d:Disease {name:'百日咳'})-[:TREATED_BY]->(dr:Drug) WHERE dr.type='抗生素' RETURN dr.name, dr.dosage
答案: 红霉素（30-50mg/kg/d）
```

**Q6: 并发症**
```
用户: 百日咳最常见的严重并发症是什么?
Cypher: MATCH (d:Disease {name:'百日咳'})-[:HAS_COMPLICATION]->(c:Complication) RETURN c.name
答案: 支气管肺炎和肺不张
```

**Q7: 中医辨证**
```
用户: 中医治疗痉咳期百日咳的主方是什么?
Cypher: MATCH (d:Disease {name:'百日咳'})-[:HAS_TCM_PATTERN]->(t:TCM_Pattern {name:'痉咳期'})-[:TREATED_BY_TCM]->(dr:Drug) RETURN dr.name
答案: 桑白皮汤
```

**Q8: 预防措施**
```
用户: 百日咳患者的隔离期应持续多久?
Cypher: MATCH (d:Disease {name:'百日咳'})-[:REQUIRES_PRECAUTION]->(p:Precaution) WHERE p.type='隔离' RETURN p.duration
答案: 隔离至病后40天或痉咳后30天
```

**Q9: 护理要点**
```
用户: 护理百日咳患儿时需特别注意防范什么紧急情况?
Cypher: MATCH (d:Disease {name:'百日咳'})-[:REQUIRES_PRECAUTION]->(p:Precaution) WHERE p.type='护理' RETURN p.description
答案: 夜间突发窒息（需专人守护）
```

**Q10: 营养指导**
```
用户: 百日咳患者应避免食用哪类食物?
Cypher: MATCH (d:Disease {name:'百日咳'})-[:REQUIRES_PRECAUTION]->(p:Precaution) WHERE p.type='饮食禁忌' RETURN p.description
答案: 海鲜类（螃蟹、海虾、海螺等）
```

## 四、非功能需求

### 4.1 性能要求
- 响应时间 < 500ms（Agent 意图识别 + 查询生成）
- 知识图谱查询 < 200ms
- 答案生成 < 1s（含 LLM 调用）

### 4.2 质量要求
- 能处理 10 个测试案例及 30+ 变体场景
- 检索精度 >= 80%
- 实体识别准确率 >= 90%

### 4.3 扩展要求
- 支持多疾病查询（不仅限于百日咳）
- 支持组合问题（如'百日咳吃什么药，有什么副作用'）
- 支持症状反查疾病（'我咳嗽带鸡鸣声是什么病'）
