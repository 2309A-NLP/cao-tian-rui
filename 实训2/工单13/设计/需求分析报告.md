## 一、需求概述

### 1.1 业务背景
医学影像是疾病诊断的重要依据，但影像的解读需要专业医生知识。本模块旨在通过 **AI 视觉大模型 + RAG** 的方式，帮助患者上传影像图片后获得智能分析、视觉问答（VQA）和医疗报告生成服务，降低患者理解医学影像的门槛。

### 1.2 目标用户
- **主要用户**: 持有医学影像检查报告/片子的患者
- **用户特征**: 对影像内容不理解，需要通俗解释
- **使用场景**: CT、X光、MRI、超声等影像的上传和分析

## 二、功能需求

### 2.1 功能矩阵（NLP方向重点）

| 功能 | 优先级 | 说明 | 技术方案 |
|------|--------|------|----------|
| 影像上传 | P0 | 支持多种格式（DICOM、JPG、PNG） | 前端上传组件 + 后端存储 |
| VQA (视觉问答) | P0 | 用户针对影像提问，AI 回答 | 多模态大模型（如 Qwen-VL、LLaVA-Med） |
| 医疗报告生成 (MRG) | P0 | 自动生成结构化医疗报告 | LLM + 医学报告模板 |
| RAG 增强 | P0 | 结合医学文献/知识库增强回答 | 向量检索 + LLM 生成 |
| 医学成像分类 | P1 | 自动识别影像类型/部位 | CV 分类模型 |
| 目标检测 | P1 | 标注病灶区域 | YOLO / DETR |
| 分割 (B-Seg/G-Seg) | P1 | 像素级病灶分割 | SAM / MedSAM |

### 2.2 功能说明

#### VQA（视觉问答）
- 用户上传影像后，可以用自然语言提问
- 示例: '这张 CT 片上肺部有阴影吗?' '这个结节是良性的吗?'
- 系统结合图像理解和医学知识进行回答

#### 医疗报告生成（MRG）
- 自动识别影像中的关键发现
- 生成结构化报告: 检查部位、影像表现、诊断意见、建议
- 报告模板符合医学规范

#### RAG（检索增强生成）
- 建立医学影像知识库（向量数据库）
- 相似病例检索: 上传影像后检索历史相似病例
- 文献增强: 结合最新医学文献回答用户问题

## 五、非功能需求

### 5.1 性能要求
- 响应时间 < 500ms（文本交互）
- 影像上传 + 初始分析 < 5s
- 报告生成 < 3s

### 5.2 质量要求
- VQA 回答准确率 >= 80%
- 报告生成符合医学表述规范
- RAG 检索精度 >= 80%

### 5.3 安全要求
- 影像数据加密存储
- 患者隐私脱敏处理
- 分析结果免责声明（AI 辅助，非诊断依据）
