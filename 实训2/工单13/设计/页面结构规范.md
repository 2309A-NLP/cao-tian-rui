# 影像分析 - 页面结构规范

> 本规范用于在 Figma/Mastergo 中精确复刻影像分析模块的原型页面。
> 所有数值单位均为 px，颜色值为 HEX。

---

## 一、画布设置

| 属性 | 值 | 说明 |
|------|-----|------|
| 画布宽度 | 1220 | 主内容区 |
| 画布高度 | 840 | 主内容区 |
| 背景色 | #FFFFFF | 内容区表面 |
| 页面背景 | #F0FDFA | 画布底色 |

## 四、页面状态清单

| 状态 | 说明 |
|------|------|
| 未上传 | 展示上传区域 + 空状态提示 |
| 上传中 | 上传区域显示进度条 |
| 分析中 | 展示加载动画 + 分析步骤 |
| 分析完成 | 展示报告卡片 + 影像预览 + VQA对话 |
| VQA 交互 | 对话气泡动态增加 |
