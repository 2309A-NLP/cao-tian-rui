| RAG_01_var1 | 检索结果字段校验 | PASS | |
| RAG_02_base | 脑部 MRI 检索 | PASS | |

| RAG_04_ct | CT 图像检索 | PASS | |
| RAG_05_mri | MRI 图像检索 | PASS | |
| RAG_06_ct | CT 图像检索变体 | PASS | |
