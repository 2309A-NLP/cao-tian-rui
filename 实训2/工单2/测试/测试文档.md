# 日程提醒智能体 — 测试文档

## 一、验收测试用例及结果

### 测试环境
- 服务地址：http://localhost:8001
- 模型：deepseek-ai/DeepSeek-V3（硅基流动）
- 数据库：MySQL 8.0，库名 agent_schedule_reminder

---

### TC-01：基础日程添加（口语化时间）

**输入：** `添加日程：下午5点开会`

**预期：**
- 调用 `add_schedule`
- title="开会"，schedule_time="17:00"，schedule_date=今天

**实际结果：** ✅ 通过
```
工具调用: add_schedule
参数: {"title": "开会", "schedule_date": "2026-06-23", "schedule_time": "17:00", "repeat_type": "none"}
回复: 好的主人～已为您添加日程：今天 17:00「开会」⏰
```

---

### TC-02：竖线格式特殊输入（验收测试语句）

**输入：** `15:15|0000001|提醒我买咖啡`

**预期：**
- 解析格式：时间=15:15，用户ID=0000001（忽略），事项=买咖啡
- title="买咖啡"（去掉"提醒我"前缀）

**实际结果：** ✅ 通过
```
工具调用: add_schedule
参数: {"title": "买咖啡", "schedule_date": "2026-06-23", "schedule_time": "15:15"}
```

---

### TC-03：查询今日日程（验收测试语句）

**输入：** `我今天的日程有哪些？`

**预期：**
- 调用 `query_schedules(schedule_date=今天)`
- 按时间升序展示
- 不显示 DB_ID

**实际结果：** ✅ 通过
```
工具调用: query_schedules
回复:
1. 12:00 提醒您吃饭
2. 15:15 买咖啡
3. 17:00 开会
4. 17:30 提醒您吃药
```

---

### TC-04：删除日程（验收测试语句）

**输入（第1步）：** `取消日程1`

**预期：** 先查询，展示第1条日程详情，等待确认

**实际结果（第1步）：** ✅ 通过
```
工具调用: query_schedules → delete_schedule(confirmed=false, schedule_id=DB_ID)
回复: 主人，您要取消的日程是：
  12:00「提醒您吃饭」
  确认取消吗？
```

**输入（第2步）：** `确认`

**实际结果（第2步）：** ✅ 通过
```
工具调用: delete_schedule(confirmed=true, schedule_id=34)
回复: ✅ 已删除日程，内容：12:00 提醒您吃饭
```

---

### TC-05：到时提醒话术（验收测试语句）

**触发条件：** 日程时间到达，后台提醒线程检测到

**实际结果：** ✅ 通过
```
弹出提醒横幅：温馨提醒：「开会」的时间到啦，主人！✨
（5 种话术随机选择）
```

### TC-06：完整性引导（缺字段追问）

**输入：** `添加一个日程`

**预期：** 不调工具，追问缺少的信息

**实际结果：** ✅ 通过
```
工具调用: 无
回复: 好的主人～请问：
  1️⃣ 要提醒的是什么事呢？
  2️⃣ 什么时间呢？（比如：下午3点、明天上午8点）
```

---

### TC-07：循环日程（复杂理解）

**输入：** `每个工作日早上9点站会`

**预期：**
- repeat_type="weekly"
- repeat_rule={"weekdays":[1,2,3,4,5]}

**实际结果：** ✅ 通过
```
工具调用: add_schedule
参数: {
  "title": "站会",
  "schedule_time": "09:00",
  "repeat_type": "weekly",
  "repeat_rule": "{\"weekdays\":[1,2,3,4,5]}"
}
```

### TC-08：重复日程检测

回复: 主人，您今天已有「开会」的日程了，是否要重复添加一条？
