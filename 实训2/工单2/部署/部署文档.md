## 二、部署步骤

### 步骤1：获取项目代码

```bash
# 项目目录
E:\实训2\2--工单2\
```

### 步骤2：配置 API Key（必须）

复制 `.env.example` 为 `.env`，填入真实值：

```bash
# E:\实训2\2--工单2\.env
AGENT_LLM_KEY=sk-你的硅基流动APIKey
AGENT_DB_PASS=你的MySQL密码
```

**获取硅基流动 API Key：**
1. 登录 https://cloud.siliconflow.cn
2. 进入「API密钥」页面
3. 创建新密钥，复制到 `.env`

### 步骤3：确认 config.json

```json
{
  "llm_base_url": "https://api.siliconflow.cn/v1",
  "llm_model": "deepseek-ai/DeepSeek-V3",
  "llm_temperature": 0.3,
  "db_host": "127.0.0.1",
  "db_port": 3306,
  "db_user": "root",
  "db_name": "agent_schedule_reminder",
  "log_dir": "logs",
  "max_tool_call_rounds": 5
}
```

修改 `db_host`、`db_user` 等字段以匹配实际 MySQL 配置。

### 步骤4：启动 MySQL

确保 MySQL 8.0 已启动，数据库会在首次运行时自动创建。

```bash
# Windows 服务启动
net start mysql80
# 或通过 XAMPP/MySQL Workbench 启动
```

### 步骤5：启动服务

```bash
cd E:\实训2\2--工单2
python run.py
```

## 四、端口冲突处理

如果启动时报 `[Errno 10048]` 端口已占用：

```bash
# 查找占用端口的进程（以8001为例）
netstat -ano | findstr 8001

# 终止进程（替换 PID 为实际值）
taskkill /F /PID <PID>
```

或修改 `run.py` 中的端口号：
```python
uvicorn.run("api.api:app", host="0.0.0.0", port=8002)  # 改为其他端口
```

## 五、服务器部署注意事项

### 5.1 安全配置

- `.env` 文件**绝对不能**上传到 GitHub 或代码仓库
- 服务器上通过环境变量注入（而非 `.env` 文件）：
  ```bash
  export AGENT_LLM_KEY=sk-xxx
  export AGENT_DB_PASS=密码
  python run.py
  ```

### 5.2 数据库远程访问

如果 MySQL 不在同一服务器，修改 `config.json`：
```json
{
  "db_host": "数据库服务器IP",
  "db_port": 3306,
  "db_user": "专用用户名"
}
```

### 5.3 反向代理（Nginx）

生产环境建议在 Nginx 前配置 HTTPS：
```nginx
location / {
    proxy_pass http://127.0.0.1:8001;
    proxy_http_version 1.1;
    proxy_set_header Upgrade $http_upgrade;
    proxy_set_header Connection "upgrade";
    # SSE 需要关闭缓冲
    proxy_buffering off;
    proxy_cache off;
}
```

### 5.4 提醒功能限制

| 限制 | 说明 |
|------|------|
| 浏览器必须保持打开 | 提醒依赖前端15秒轮询，关闭浏览器不提醒 |
| 最大延迟45秒 | 后端30s扫描 + 前端15s拉取 |
| 重启丢失待推提醒 | 提醒队列在内存，服务重启后清空 |
