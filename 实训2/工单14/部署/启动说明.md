## 一、依赖前置

### 1.1 上游工单服务

MCP 网关本身只是编排层。要看到端到端效果，需要至少启动以下上游服务：

| 服务 | 端口 | 状态 | 依赖 |
|---|---|---|---|
| 工单01 挂号管理 | 8011 | 🟡 推进中 | MySQL |
| 工单02 健康咨询 | 8012 | 🟢 接近完成 | Neo4j |
| 工单03 影像分析 | 8013 | 🔴 未开工（占位） | - |
| 工单05 语音识别 | 8015 | 🔴 未开工（占位） | - |

**没启动的上游会自动返回 not_implemented 或连接失败，前端仍可正常展示地图/路线/周边功能。**

### 1.2 高德开放平台密钥（必配）

到 <https://console.amap.com/dev/key/app> 申请 3 个 Key：
- Web 服务 Key → 填入 `AMAP_API_KEY`
- JS API Key → 填入 `AMAP_JS_KEY`
- JS API 安全密钥 → 填入 `AMAP_JS_SECURITY_CODE`

详见 [docs/高德MCP对接文档.md](docs/高德MCP对接文档.md)

### 1.3 硅基流动 LLM Key

到 <https://siliconflow.cn> 申请 API Key → 填入 `SILICONFLOW_API_KEY`

## 七、常见问题

**Q1: `pool.call` 报"tool xxx 不存在"？**
A: 该 MCP Server 启动失败（看 `[pool] ✗ xxx` 日志）。通常是 `mcp_servers/*.py` import 报错，
   把命令改成 `python -m mcp_servers.xxxxx_mcp` 单独跑一下看错误。

**Q2: 前端地图空白？**
A: 打开浏览器 DevTools Network 面板：
   - `/api/amap/js-config` 应该返回 `{ok:true, js_key, security_js_code}`；否则 `.env` 里 Key 没配
   - `webapi.amap.com/maps` 应该 200；若失败通常是 Key 错误或域名白名单未设

**Q3: 路由精度不到 80%？**
A: 排查方向：
   - LLM 是否用的 Qwen2.5-72B（低参数模型可能漂）
   - SYSTEM_PROMPT 里对每类工具的描述是否清晰
   - 用例是否有歧义（可以调整用例，但不改评测门槛）

**Q4: 想临时禁用某个 MCP Server？**
A: 在 `mcp_client/router_agent.py` 里 `SERVERS` 列表里注释掉即可。
