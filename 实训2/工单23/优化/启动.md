## agent23 启动完整指令

agent23 是 **Flask 服务**（非 FastAPI），venv 目录名为 `.venv`，端口默认 **8023**。

### PowerShell



```powershell
cd "F:\kimi  project\agent23"
.\.venv\Scripts\Activate.ps1
python src/app.py
```

### CMD



```bat
cd /d "F:\kimi  project\agent23"
call .venv\Scripts\activate.bat
python src/app.py
```

------

### 启动后访问地址

| 地址                                           | 说明                                           |
| ---------------------------------------------- | ---------------------------------------------- |
| `http://localhost:8023`                        | 前端页面（index.html）                         |
| `http://localhost:8023/api/v1/chat`            | 对话接口（POST，body: `{"question": "..."}` ） |
| `http://localhost:8023/api/v1/status/<req_id>` | 前端进度轮询                                   |
| `http://localhost:8023/health`                 | 健康检查                                       |

------

### 关键依赖说明

| 必填配置                     | 说明                     |
| ---------------------------- | ------------------------ |
| `DASHSCOPE_API_KEY`          | 已配置（阿里云百炼）     |
| `IQS_API_KEY` / `IQS_APP_ID` | 已配置（首选搜索引擎）   |
| `BING_API_KEY`               | 未填（备用，可不填）     |
| `SERPAPI_KEY`                | 未填（最后备用，可不填） |

`.env` 文件已存在且关键 Key 已填入，直接启动即可。配置缺失时服务会**降级运行**（警告但不退出）。

------

> **注意**：
>
> - venv 目录是 `.venv`（有点号），区别于 agent22 的 `venv`
> - 路径含**双空格** `F:\kimi project`，引号不能省
