### 2.2 测试用例集

#### 用例1：A股行情查询（单行结果）

**输入**：
```
在20210715，中信行业分类划分的一级行业为消费者服务行业中，涨跌幅最大股票的股票代码是？涨跌幅是多少？百分数保留两位小数。
```

**预期结果**：
- 问题类型：数据库类
- 回答：`股票代码：300178，涨跌幅：4.62`
- SQL：含 `("收盘价(元)" - "昨收盘(元)") / "昨收盘(元)" * 100` 的计算
- 耗时：NL2SQL ~6-9s，SQL <1s，回答 0s

**验证要点**：
- 股票代码必须是6位数字（300178），不能多位或少位
- 涨跌幅数值正确（4.62，非4.60等近似值）

## 5. 数据库查询验证

直接查询数据库，与 Gradio 输出对比，确认 SQL 结果正确：

```python
import sqlite3
conn = sqlite3.connect(r"E:\16---实训2\4--工单4\data\博金杯比赛数据.db")
cur = conn.cursor()

# 验证用例1：消费者服务行业涨跌幅最大股票
cur.execute('''
SELECT a."股票代码",
       ROUND(((a."收盘价(元)" - a."昨收盘(元)") / a."昨收盘(元)") * 100, 2) AS 涨跌幅
FROM "A股票日行情表" a
JOIN "A股公司行业划分表" i ON a."股票代码" = i."股票代码" AND a."交易日" = i."交易日期"
WHERE a."交易日" = '20210715'
  AND i."行业划分标准" = '中信行业分类'
  AND i."一级行业名称" = '消费者服务'
  AND a."昨收盘(元)" > 0
ORDER BY 涨跌幅 DESC
LIMIT 1
''')
print(cur.fetchone())  # 期望: ('300178', 4.62)
conn.close()
```
