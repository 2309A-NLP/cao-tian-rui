# 工单4：基金数据问答智能体 · 设计文档

## 1. 需求分析

**输入**：1000道自然语言问题（`question.jsonl`），涵盖基金/股票/债券历史数据查询及招股书问题

**输出**：
- `outputs/answers.jsonl`：1000题自然语言回答
- Gradio 网页演示（截图提交用）
- LangChain Tool 接口（供工单6调用）

**约束**：
- 不能手写或拼接 SQL，必须使用 NL2SQL（LLM 动态生成）
- API Key 不能硬编码，从 `.env` 读取
- 支持断点续跑，中途停止不丢已完成结果

---

## 2. 技术选型

| 组件 | 选择 | 备选方案 | 选择理由 |
|---|---|---|---|
| 数据库 | SQLite 只读模式 | MySQL | 数据为静态文件（1.46GB .db），无需服务器，零运维 |
| NL2SQL 模型 | DeepSeek-V3（硅基流动） | Qwen2.5-72B | MoE 架构，SQL 能力强，激活约 37B 参数 |
| 回答生成 | 直接格式化 / Qwen2.5-7B | Qwen2.5-72B | 简单结果无需 LLM；复杂结果用 7B 节省时间 |
| Tool 接口 | LangChain Tool | 自定义 HTTP API | 工单6统一规范 |
| Web UI | Gradio | Streamlit / Flask | 快速开发，内置示例功能 |

## 4. 数据库设计

数据库文件：`data/博金杯比赛数据.db`（SQLite，1.46GB），只读访问，不做任何写操作。

### 4.1 数据表清单

| 表名 | 主要字段 | 说明 |
|---|---|---|
| A股票日行情表 | 股票代码、交易日、收盘价(元)、昨收盘(元) | A股每日行情 |
| A股公司行业划分表 | 股票代码、交易日期、行业划分标准、一级行业名称 | 中信行业分类 |
| 基金基本信息 | 基金代码、基金简称、管理人、基金类型 | 基金元数据 |
| 基金股票持仓明细 | 基金代码、持仓日期、第N大重仓股 | 季报持股 |
| 基金债券持仓明细 | 基金代码、持仓日期、债券名称、第N大重仓股 | 季报持债 |
| 基金可转债持仓明细 | 基金代码、持仓日期、**对应股票代码**、**债券名称** | 列名特殊，见实现文档 |
| 基金日行情表 | 基金代码、交易日期、单位净值 | 基金净值 |
| 基金规模变动表 | 基金代码、截止日期 | 申赎规模 |
| 基金份额持有人结构 | 基金代码、定期报告所属年度 | 机构/个人占比 |
| 港股票日行情表 | 股票代码、交易日 | 港股行情 |

### 4.2 索引设计

对所有表的高频查询字段建立索引（共 28 个），关键索引：

```sql
-- 最常用：股票行情按日期+行业联合查
CREATE INDEX idx_a股行情_代码日期 ON "A股票日行情表"("股票代码", "交易日");
CREATE INDEX idx_行业_标准       ON "A股公司行业划分表"("行业划分标准");
CREATE INDEX idx_行业_一级行业   ON "A股公司行业划分表"("一级行业名称");

-- 基金查询：按名称+代码关联
CREATE INDEX idx_基金基本_简称   ON "基金基本信息"("基金简称");
CREATE INDEX idx_债券持仓_基金代码 ON "基金债券持仓明细"("基金代码");
```

## 5. 预分类器设计

为节省 API 成本，在 NL2SQL 之前用关键词规则分类问题。

### 5.1 分类逻辑

```
1. 含强数据库信号词（涨跌幅、收盘价、持仓等） → db（直接走 NL2SQL）
2. 含招股书信号词（首发、员工人数、竞争优势等） → prospectus（跳过，返回标记）
3. 含8位纯数字日期（如 20210105） → db
4. 其余 → unknown（保守处理，走 NL2SQL）
```

### 5.2 关键词列表摘要

**DB 强信号词**（优先级最高）：
涨跌幅、涨停、收盘价、开盘价、净值、持仓、基金规模、份额、一级行业、季报、年报……

**招股书信号词**：
首发、首次公开、战略配售、竞争优势、实际控制人、员工人数、募投项目、主要客户……

### 5.3 效果

1000题中约 **63题**被预分类为招股书类，零 API 成本直接返回 `__PROSPECTUS__` 标记，供工单6路由到工单5处理。

## 6. NL2SQL 提示词设计

### 6.1 核心规则（共18条，关键摘录）

| 规则 | 内容 |
|---|---|
| 规则3 | 日期字段为文本 YYYYMMDD，直接字符串比较，不用 DATE() |
| 规则5 | 涨跌幅固定公式：`("收盘价(元)" - "昨收盘(元)") / "昨收盘(元)" * 100`，禁止自连接 |
| 规则9 | 表名和列名必须用双引号，含括号列名如 `"收盘价(元)"` |
| 规则11 | A股票日行情表完整列名示例 |
| 规则11b | 基金可转债持仓明细无 `股票代码` 列，正确列名为 `对应股票代码`、`债券名称` |
| 规则13 | 禁止猜测/硬编码基金代码，必须 JOIN 基金基本信息通过名称查代码 |
| 规则16 | 行业划分标准精确匹配 `= '中信行业分类'`，不用 LIKE（会导致索引失效） |
| 规则17 | 定性描述类问题（原因、背景等）输出占位 SQL，不查数据库 |

## 7. 工单6接口设计

```python
# fund_agent.py 对外暴露两种接口

# 接口1：LangChain Tool（工单6统一规范）
fund_db_tool = LangChainTool(
    name="基金数据问答",
    description="查询基金、股票、债券的结构化历史数据（2019-2021年）...",
    func=lambda q: get_agent().query(q),
)

# 接口2：直接调用
agent = get_agent()
answer = agent.query("你的问题")

# 返回值约定：
# - 正常回答：自然语言字符串
# - 招股书问题：字符串 "__PROSPECTUS__"（工单6据此路由到工单5）
# - 查无数据：字符串 "未查询到相关数据..."
```
