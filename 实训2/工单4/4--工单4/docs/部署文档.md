## 3. 配置文件

复制模板并填写真实值：

```bash
copy .env.example .env
```

`.env` 各字段说明：

```env
# 硅基流动 API Key（必填）
SILICONFLOW_API_KEY=sk-xxxx

# API 地址（默认不用改）
SILICONFLOW_BASE_URL=https://api.siliconflow.cn/v1

# NL2SQL 使用的模型（推荐大模型，准确率更高）
NL2SQL_MODEL=deepseek-ai/DeepSeek-V3

# 回答生成使用的模型（简单结果会跳过，复杂结果调此模型）
ANSWER_MODEL=Qwen/Qwen2.5-7B-Instruct

# 数据库路径（相对路径以项目根目录为基准）
DB_PATH=./data/博金杯比赛数据.db

# 题目文件路径
QUESTION_FILE=./question.jsonl

# 输出文件路径
OUTPUT_FILE=./outputs/answers.jsonl

# SQL执行失败最大重试次数
MAX_RETRY=3

# 批量处理每题间隔（秒），防止触发限流
REQUEST_INTERVAL=5
```

> **注意**：`.env` 文件包含 API Key，不能上传到 Git 仓库。

## 6. 常见部署问题

### 问题：`ModuleNotFoundError: No module named 'gradio'`

未在虚拟环境中安装依赖。确认使用的是虚拟环境的 Python：

```bash
# 错误：使用了系统Python
python app.py

# 正确：使用虚拟环境Python
venv\Scripts\python app.py
```

### 问题：`FileNotFoundError: data\博金杯比赛数据.db`

从错误的目录运行了脚本。必须先 `cd` 到项目根目录：

```bash
cd E:\16---实训2\4--工单4
venv\Scripts\python app.py
```

### 问题：端口 7860 被占用

上次启动的 `app.py` 进程未关闭。用 `Ctrl+C` 终止旧进程后重启，或修改 `app.py` 末尾的 `server_port=7861`（已改为 7861）。

### 问题：`Error code: 403 - Model disabled`

当前账号套餐不支持所选模型。到硅基流动模型广场（cloud.siliconflow.cn/open/models）查看可用模型，修改 `.env` 中 `NL2SQL_MODEL` 为可用的模型名。

已验证可用的模型：
- `deepseek-ai/DeepSeek-V3`（推荐）
- `Qwen/Qwen2.5-72B-Instruct`（备用，较慢）

### 问题：`attempt to write a readonly database`

数据库以只读模式打开，不能执行写操作。如 `db_utils.py` 中包含 `PRAGMA journal_mode=WAL` 需删除（该语句要求写权限）。

## 7. 工单6集成部署

工单6直接 import 工单4的模块，无需启动任何服务：

```python
import sys
sys.path.insert(0, r"E:\16---实训2\4--工单4\src")

# 方式A：LangChain Tool
from fund_agent import fund_db_tool
answer = fund_db_tool.run("你的问题")

# 方式B：直接调用
from fund_agent import get_agent
answer = get_agent().query("你的问题")
```

**工单6路由逻辑**：
- 返回 `__PROSPECTUS__` → 路由到工单5（招股书 RAG）
- 返回其他字符串 → 直接作为最终回答
