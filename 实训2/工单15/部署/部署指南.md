## 1. 环境要求

| 项目 | 要求 |
|---|---|
| Python | ≥ 3.10（已用 `dict[str, Any]` 类型注解，3.9 以下不支持） |
| 操作系统 | Windows 10/11（已在 Win11 验证）；Linux/Mac 同样可行，路径分隔符自动处理 |
| 浏览器（前端） | Chrome 94+ / Edge 94+（AudioWorklet 需 Secure Context 或 localhost） |
| 网络 | MOCK 模式：纯本地，无需外网；讯飞 IAT 模式：需访问 `wss://iat-api.xfyun.cn` |

## 2. 首次安装（一次性）

```powershell
# 进入后端目录
cd "F:\kimi  project\医疗agent1\05-实时语音识别\backend"

# 创建隔离虚拟环境（已存在则跳过）
python -m venv venv

# 安装依赖
.\venv\Scripts\pip.exe install -r requirements.txt
```

`requirements.txt` 包含：`fastapi`, `uvicorn[standard]`, `websockets`, `httpx`, `python-dotenv`, `pytest`, `pytest-asyncio`。

---

## 3. 配置 `.env`

`.env` 文件位于 `backend/.env`，已提供默认 MOCK 配置。根据目标环境按需修改：

### 3.1 MOCK 模式（开发/演示，无需任何凭据）

```ini
ASR_ENGINE=mock
MOCK_MODE=true
TRANSLATE_ENABLED=true
TRANSLATE_LANGUAGES=en
PORT=8015
```

### 3.2 真实讯飞 IAT 模式

1. 前往 [讯飞开放平台](https://www.xfyun.cn) 注册
2. 创建应用 → 开通**实时语音转写（IAT）**
3. 记录 `APP_ID / API_KEY / API_SECRET`

```ini
ASR_ENGINE=xfyun
MOCK_MODE=false
XF_APP_ID=你的APP_ID
XF_API_KEY=你的API_KEY
XF_API_SECRET=你的API_SECRET
SILICONFLOW_API_KEY=sk-xxxxxxxx     # 翻译+摘要，从 siliconflow.cn 申请
TRANSLATE_ENABLED=true
TRANSLATE_LANGUAGES=en
PORT=8015
WT12_URL=http://localhost:8012       # 工单12健康咨询地址，如未部署保持默认即可
```

### 3.3 通义听悟模式（见 `docs/通义听悟对接说明.md` §3.4）

## 4. 启动服务

```powershell
cd "F:\kimi  project\医疗agent1\05-实时语音识别\backend"
.\venv\Scripts\python.exe -m uvicorn src.app:app --host 127.0.0.1 --port 8015
```

正常启动日志（最后两行）：

浏览器访问 `http://127.0.0.1:8015/` 即可看到语音助手页面。

## 5. 验证部署

### 5.1 健康检查

```powershell
Invoke-RestMethod http://127.0.0.1:8015/health
```

MOCK 模式期望返回：
```json
{"status":"ok","mock_mode":true,"asr":"mock","translate_enabled":true,"translate_langs":["en"]}
```

真实讯飞模式期望返回：
```json
{"status":"ok","mock_mode":false,"asr":"xfyun","translate_enabled":true,"translate_langs":["en"]}
```

### 5.2 前端页面验证

1. 打开 `http://127.0.0.1:8015/`
2. 页面左上角 badge 显示"MOCK 模式"或"XFYUN 模式"（而非"连接中…"或"离线"）
3. 运行日志最后一行显示"后端就绪 · ASR=mock · MOCK=True · 翻译=True"

### 5.3 完整 MOCK 流程验证

1. 点击麦克风按钮 → 授予权限 → 自动完成 4 句模拟医患对话（约 8 秒）
2. 点击"⏹️ 结束录音并生成纪要"→ 自动切换到"📋 会议纪要"Tab
3. 查看全文摘要、章节速览、待办事项、关键词均已填充

## 6. 后台运行（长时间保持）

```powershell
# 将日志重定向到文件，后台持续运行
cd "F:\kimi  project\医疗agent1\05-实时语音识别\backend"
Start-Process -FilePath ".\venv\Scripts\python.exe" `
  -ArgumentList "-m uvicorn src.app:app --host 127.0.0.1 --port 8015" `
  -RedirectStandardOutput "..\uvicorn.log" `
  -RedirectStandardError "..\uvicorn.err" `
  -NoNewWindow

# 查看日志
Get-Content "..\uvicorn.log" -Tail 20
```

---

## 7. 停止服务

```powershell
# 找到占用 8015 端口的进程并终止
$pid = (Get-NetTCPConnection -LocalPort 8015 -State Listen).OwningProcess
Stop-Process -Id $pid -Force
```
