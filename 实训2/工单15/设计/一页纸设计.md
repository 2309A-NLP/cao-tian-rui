# 工单15 一页纸设计（Architecture Decision Record）

> 工单编号：人工智能NLP-Agent数字人项目-医疗智能体-实时语音识别、翻译与会议概要
> 版本：v1.0 / 2026-07-06

---

## 1. 目标（一句话）

对接语音识别引擎，实现 **实时中文识别 + 实时中英翻译 + 章节速览/要点提炼/摘要总结**，并同时提供**回调 URL** 与**轮询**两种结果获取方式，前端可独立运行、可嵌入总界面。

---

## 2. 关键决策与理由

| # | 决策点 | 选择 | 理由 |
|---|---|---|---|
| 1 | ASR 引擎 | **讯飞 IAT** 主 / mock 备 / tingwu 存档 | 讯飞签名简单（HMAC-SHA256）、本地无需公网回调、免费额度足够开发；PDF 要求"通义听悟"通过 `tingwu.py` 存档满足合规。三态由 `ASR_ENGINE` 切换 |
| 2 | 翻译 | **句末事件触发硅基流动 Qwen2.5** | 讯飞不含翻译；再引入百度/DeepL 增加凭据依赖，硅基流动已在其他工单使用，共用 API Key 更省 |
| 3 | 摘要 | **硅基流动 Qwen2.5 结构化输出** | 与 PDF 通义听悟返回字段 `Chapters/Summarization` 对齐，方便前端一套渲染逻辑 |
| 4 | 回调路径 | **保留 `/api/callback`** | PDF 明确要求"回调 URL 和轮询都要实现"；即使当前不走通义听悟，也保留该端点便于外部 Agent 异步推结果 |
| 5 | 轮询路径 | **`/api/session/{id}/poll` 3s×30 次** | PDF 明确要求；返回 `TaskStatus/Result` 通义听悟风格字段 + 兼容旧小写字段 |
| 6 | 并发模型 | **asyncio 协程 + gather** | 需求分析报告原稿写的"多线程"不合适——FastAPI 是 async 优先，用 `asyncio.gather` 跑上下行两个协程，无锁开销 |
| 7 | 前端框架 | **纯 HTML + Vanilla JS + AudioWorklet** | 无构建、易嵌入总界面；旧 `ScriptProcessor` API 已废弃，AudioWorklet 更稳 |
| 8 | 前端配色 | **复用 00-总界面框架 design-tokens（Teal-600 #0D9488）** | 与总界面视觉一致，替换旧原型的蓝色 `#1a73e8` |
| 9 | 集成方式 | **阶段一 iframe / 阶段二组件** | 先解耦，5 工单都完成后再统一抠成组件塞进总界面 index.html |
| 10 | MCP | **不用** | 工单14 才是 MCP 专项；流式音频与 MCP `tool_call` 回合制不匹配；直接 HTTP+WS 更清晰 |
| 11 | 打包 | **本轮不打包 Docker** | 按用户要求最后一次性打包，避免改动重复更新容器 |

## 5. API 契约

### WebSocket `/ws/stream`

**客户端 → 服务端**
| 帧类型 | 内容 | 说明 |
|---|---|---|
| 文本 | `{"type":"init","lang":"zh_cn","task_id":"..."}` | 首帧（`task_id` 可选） |
| 二进制 | PCM 16kHz 16bit mono | 每帧 40ms（1280 字节） |
| 文本 | `{"type":"stop"}` | 结束录音 |

**服务端 → 客户端**
| 事件 | Payload |
|---|---|
| `started` | `{task_id}` |
| `log` | `{message}` |
| `transcription` | `{text, is_final, speaker}` |
| `sentence_end` | `{text, speaker, begin_ms, end_ms}` |
| `translation` | `{text, target_lang, sentence_index}` |
| `completed` | `{task_id}` |
| `error` | `{message}` |

### REST

| 方法 | 路径 | 用途 |
|---|---|---|
| GET  | `/health` | 健康+ASR 引擎状态 |
| POST | `/api/session/start` | 创建会话（CreateTask 语义），返回 `task_id` + `meeting_join_url` |
| POST | `/api/session/{id}/stop` | 停止会话 |
| GET  | `/api/session/{id}/poll` | 轮询结果（大写字段 + 小写兼容） |
| GET  | `/api/session/{id}/summary` | 会议纪要视图 |
| POST | `/api/session/{id}/consult` | 转写发给工单12 健康咨询 |
| POST | `/api/callback` | 接收通义听悟风格回调 |
