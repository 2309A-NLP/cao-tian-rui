# 语音助手 - 页面结构规范

> 本规范用于在 Figma/Mastergo 中精确复刻语音助手模块的原型页面。
> 所有数值单位均为 px，颜色值为 HEX。

---

## 一、画布设置

| 属性 | 值 | 说明 |
|------|-----|------|
| 画布宽度 | 1220 | 主内容区 |
| 画布高度 | 840 | 主内容区 |
| 背景色 | #FFFFFF | 内容区表面 |
| 页面背景 | #F0FDFA | 画布底色 |

---

## 二、整体布局

```
+--------------------------------------------------+
| [模块标题] 语音助手                               |
| [Tab] 实时录音 | 会议纪要                         |
+--------------------------------------------------+
|                                                   |
|  [实时录音面板]                                   |
|  [语言选择] 中文(主) <-> 英文(译)                 |
|                                                   |
|  [麦克风按钮] (大圆形居中)                        |
|  [录音状态文字]                                   |
|                                                   |
|  [实时转写区域]                                   |
|  [说话人标签 + 识别文本 + 翻译]                   |
|  [操作按钮行] 暂停/结束/设置                      |
|                                                   |
+--------------------------------------------------+
|  [会议纪要面板] (Tab 切换显示)                    |
|  [会议信息行] 时间/导出/复制                      |
|  [摘要面板] 全文摘要/章节速览/待办/问答/关键词     |
|                                                   |
+--------------------------------------------------+
```

## 四、页面状态清单

| 状态 | 说明 |
|------|------|
| 未录音 | 麦克风默认态 + 提示文字 |
| 录音中 | 麦克风红色脉冲态 + 实时转写 |
| 暂停 | 麦克风暂停态 + 转写暂停 |
| 录音结束 | 跳转会议纪要 Tab |
| 纪要生成中 | 加载动画 |
| 纪要完成 | 展示完整纪要面板 |

## 六、动画规范

| 动画名称 | 时长 | 效果 | 用途 |
|----------|------|------|------|
| pulse-red | 1.5s | scale 1 -> 1.08 -> 1 | 录音中麦克风脉冲 |
| ripple | 2s | scale 1 -> 1.3, opacity 1 -> 0 | 麦克风波纹扩散 |
