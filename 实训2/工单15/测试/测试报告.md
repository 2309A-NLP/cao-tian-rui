## 四、E2E 全链路 WebSocket 验证

### 测试方式

使用 Python WebSocket 客户端脚本模拟浏览器连接，通过 uvicorn 运行的真实服务器（非 TestClient）：

```python
import asyncio, websockets, json

async def test():
    async with websockets.connect("ws://127.0.0.1:8015/ws/stream") as ws:
        await ws.send(json.dumps({"type":"init","lang":"zh_cn"}))
        while True:
            msg = json.loads(await ws.recv())
            print(msg["type"])
            if msg["type"] == "completed":
                break

asyncio.run(test())
```

### 收到事件序列（实际）

| 事件类型 | 次数 | 说明 |
|---|---|---|
| `started` | 1 | 会话创建，返回 task_id |
| `transcription` | 12 | 每句 3 次增量识别 |
| `sentence_end` | 4 | 4 句医患对话完成 |
| `translation` | 4 | 每句对应 1 条英译 |
| `completed` | 1 | 全部完成 |

总计 22 个事件，顺序符合预期。

## 七、已知限制

| 限制 | 说明 | 影响 |
|---|---|---|
| 说话人分离 | 讯飞 IAT 标准版不提供说话人分离，按句序奇偶模拟医/患角色 | 多人场景不准确，可升级讯飞会议版 |
| 无持久化存储 | 会话数据存内存，服务重启后丢失 | 重启需重新录音；后续可接 Redis |
| 摘要仅限 MOCK | SILICONFLOW_API_KEY 未配置时翻译和摘要均降级为空 | 需填 `.env` 才有真实摘要 |
