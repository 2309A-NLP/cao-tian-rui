# 挂号管理 - 页面结构规范

> 本规范用于在 Figma/Mastergo 中精确复刻挂号管理模块的原型页面。
> 所有数值单位均为 px，颜色值为 HEX。

---

## 一、画布设置

| 属性 | 值 | 说明 |
|------|-----|------|
| 画布宽度 | 1220 | 主内容区（扣除侧边栏 220px） |
| 画布高度 | 840 | 主内容区（扣除顶部栏 60px） |
| 背景色 | #FFFFFF | 内容区表面 |
| 页面背景 | #F0FDFA | 画布底色（可见区域） |

---

## 二、全局布局网格

```
+--------------------------------------------------+
| 顶部栏 (TopBar) 高度: 60px                        |

+----------+---------------------------------------+
| 侧边栏   | 主内容区 (1220 x 840)                  |
| 220px    |                                       |
|          |  内边距: 24px                         |

|          |  [模块标题]                           |

```

## 四、页面状态清单

| 状态 | 说明 | 交互配置 |
|------|------|----------|
| 号源查询页 (默认) | 展示筛选栏 + 号源表格 | 默认加载 |
| 我的预约页 | 展示已预约记录卡片 | Tab 切换 |
| 医生排班页 | 展示医生信息 + 排班日历 | Tab 切换 |
| 预约确认弹窗 | 展示预约详情 + 确认/取消按钮 | 点击预约按钮触发 |
| 预约成功状态 | 弹窗关闭后表格刷新 | 自动跳转 |
