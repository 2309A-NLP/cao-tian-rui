# 医疗智能体 Agent — 总界面框架设计文档

## 1. 设计概述

### 1.1 产品定位
**健康助理 Agent** — 面向患者用户的智能化医疗健康服务平台，整合挂号管理、健康咨询、影像分析、地图服务、实时语音五大核心能力，以对话式交互为核心入口，提供一站式医疗健康管理体验。

### 1.2 设计理念
- **专业可信**：医疗蓝绿色调传递专业、安全、值得信赖的品牌感知
- **温暖亲和**：圆角设计、柔和阴影、微动效，降低医疗场景的心理门槛
- **智能高效**：AI Agent 对话式交互，自然语言即可完成复杂操作
- **清晰层级**：信息架构扁平化，3步内触达任何功能

### 1.3 色彩规范

| 角色 | 色值 | 用途 |
|------|------|------|
| 主色 Primary | `#0D9488` (Teal-600) | 导航选中、主按钮、品牌标识 |
| 辅助色 Secondary | `#06B6D4` (Cyan-500) | 次级按钮、标签、图标 |
| 背景色 Background | `#F0FDFA` (Teal-50) | 页面背景、卡片底色 |
| 表面色 Surface | `#FFFFFF` | 卡片、弹窗、输入框 |
| 主文字 Text Primary | `#134E4A` (Teal-900) | 标题、重要文本 |
| 次文字 Text Secondary | `#5F7976` (Teal-600-灰) | 正文、描述 |
| 强调色 Accent | `#F59E0B` (Amber-500) | 警告、待办、高亮 |
| 成功色 Success | `#10B981` (Emerald-500) | 成功状态、确认 |
| 错误色 Error | `#EF4444` (Red-500) | 错误提示、删除 |

### 1.4 字体规范
- 中文：`"PingFang SC", "Microsoft YaHei", "Noto Sans SC", sans-serif`
- 英文/数字：`"Inter", "SF Pro Display", -apple-system, sans-serif`
- 标题：18px / 600 weight
- 正文：14px / 400 weight
- 辅助文本：12px / 400 weight

### 1.5 间距规范
- 页面内边距：24px
- 卡片内边距：20px
- 卡片间距：16px
- 元素间距：12px / 8px
- 圆角：卡片 16px，按钮 12px，标签 8px，头像 50%

## 3. 核心交互流程

### 3.1 用户旅程

```
[打开应用]
    |
    v
[数字人大厅] --语音/文字--> "帮我挂一个儿科专家的号"
    |                           |
    v                           v
[意图识别] <--------------- Agent 解析意图
    |
    |-- 挂号意图 --> 切换至挂号模块 --> 展示号源/完成预约
    |-- 咨询意图 --> 切换至咨询模块 --> 知识图谱查询/生成答案
    |-- 影像意图 --> 切换至影像模块 --> 上传图片/分析报告
    |-- 出行意图 --> 切换至地图模块 --> 位置查询/路线规划
    |-- 语音意图 --> 切换至语音模块 --> 开始录音/实时翻译
```

### 3.2 状态管理
- **全局状态**：用户信息、当前选中模块、未读通知、系统设置
- **模块状态**：各模块独立管理自己的业务数据
- **会话状态**：对话历史、上下文、Agent 思考过程

## 5. 与 Figma/Mastergo 的对应关系

本设计文档对应的 HTML 原型可直接在浏览器中预览交互效果。如需在 Figma/Mastergo 中复现：

1. **创建文件**：在 Mastergo 中创建 "医疗智能体 Agent" 项目
2. **建立样式库**：按"色彩规范"创建 Color Style，按"字体规范"创建 Text Style
3. **制作组件**：
   - 原子组件：Button、Input、Tag、Avatar、Icon
   - 分子组件：NavItem、ChatBubble、InfoCard、StatusBadge
   - 有机体组件：Sidebar、TopBar、ChatPanel、ModulePanel
4. **搭建页面**：
   - Frame 1: 首页-数字人大厅
   - Frame 2: 挂号管理
   - Frame 3: 健康咨询
   - Frame 4: 影像分析
   - Frame 5: 出行服务
   - Frame 6: 语音助手
5. **添加交互**：使用 Mastergo 原型模式，配置页面跳转和组件状态切换

> **提示**：本目录下的 `index.html` 文件为可直接运行的总界面框架原型，建议在 Chrome 浏览器中打开预览。
