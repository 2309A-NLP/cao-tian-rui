## 三、首次部署步骤

### 3.1 数据库初始化

```sql
-- 在 MySQL 8.0 中执行
CREATE DATABASE IF NOT EXISTS medical_agent CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
CREATE USER IF NOT EXISTS 'medical'@'localhost' IDENTIFIED BY 'your_password';
GRANT ALL PRIVILEGES ON medical_agent.* TO 'medical'@'localhost';
FLUSH PRIVILEGES;
```

```powershell
# 执行建表 DDL
cd "F:\kimi  project\医疗agent1\01-挂号管理\backend"
mysql -u medical -p medical_agent < scripts\schema_mysql.sql
```

### 3.2 创建虚拟环境并安装依赖

```powershell
cd "F:\kimi  project\医疗agent1\01-挂号管理\backend"
python -m venv venv
.\venv\Scripts\pip install -r requirements.txt
```

### 3.3 配置 .env

```ini
# F:\kimi  project\医疗agent1\01-挂号管理\backend\.env

# 数据库
DB_HOST=127.0.0.1
DB_PORT=3306
DB_NAME=medical_agent
DB_USER=root
DB_PASSWORD=root

# 阿里云百炼 LLM（主模型，优先级1）
BAILIAN_API_KEY=sk-xxxxxxxxxxxxxxxx
BAILIAN_BASE_URL=https://dashscope.aliyuncs.com/compatible-mode/v1
BAILIAN_MODEL=qwen3.7-plus

# 硅基流动 LLM（兜底，优先级2/3）
SILICONFLOW_API_KEY=sk-xxxxxxxxxxxxxxxx
SILICONFLOW_BASE_URL=https://api.siliconflow.cn/v1
SILICONFLOW_MODEL=Qwen/Qwen2.5-32B-Instruct

# API 鉴权（空=开发模式不校验）
API_KEY=

# CORS（前端门户用 http.server 启动时使用的端口）
CORS_ORIGINS=http://localhost:8080,http://127.0.0.1:8080,http://localhost:8011,http://127.0.0.1:8011,http://localhost:8000,http://127.0.0.1:8000
```

### 3.4 写入种子数据

```powershell
cd "F:\kimi  project\医疗agent1\01-挂号管理\backend"
# 首次初始化
.\venv\Scripts\python.exe scripts\init_db.py

# 数据重置（清空所有演示数据后重新初始化，用于测试数据混乱时）
.\venv\Scripts\python.exe scripts\init_db.py --reset
```

> `--reset` 会按外键依赖顺序清空全部业务表再重建，排班范围为 today-21 天 ~ today+14 天。

## 四、日常启动

> 每次测试需开两个 PowerShell 窗口，分别执行以下指令（不能换行合并）。

### 窗口 1 — 后端服务

```powershell
cd "F:\kimi  project\医疗agent1\01-挂号管理\backend"; .\venv\Scripts\python.exe -m uvicorn src.app:app --host 127.0.0.1 --port 8011 --reload
```

启动成功标志：
```
INFO:     Uvicorn running on http://127.0.0.1:8011 (Press CTRL+C to quit)
INFO:     Application startup complete.
```

### 窗口 2 — 门户静态服务

```powershell
cd "F:\kimi  project\医疗agent1\00-总界面框架"; python -m http.server 8000
```

启动成功标志：
```
Serving HTTP on 0.0.0.0 port 8000 (http://0.0.0.0:8000/) ...
```

### 访问

```
http://localhost:8000/
```

## 五、端口冲突处理

若提示端口 8011 已被占用：

```powershell
# 查找占用进程
netstat -ano | findstr ":8011"

# 根据 PID 杀掉（替换 <PID>）
Stop-Process -Id <PID> -Force
```
