## agent22 启动完整指令

### 方式一：直接运行 start.bat（最简）



```bat
"F:\kimi  project\agent22\backend\start.bat"
```

或在命令提示符里：



```bat
cd /d "F:\kimi  project\agent22\backend"
start.bat
```

------

### 方式二：手动逐步启动（PowerShell）



```powershell
cd "F:\kimi  project\agent22\backend"
.\venv\Scripts\Activate.ps1
uvicorn main:app --host 0.0.0.0 --port 8022 --reload
```

------

### 方式三：手动逐步启动（CMD）



```bat
cd /d "F:\kimi  project\agent22\backend"
call venv\Scripts\activate.bat
uvicorn main:app --host 0.0.0.0 --port 8022 --reload
```

------

### 启动后访问地址

| 地址                               | 说明                    |
| ---------------------------------- | ----------------------- |
| `http://localhost:8022`            | 前端页面（含静态文件）  |
| `http://localhost:8022/docs`       | FastAPI 交互式 API 文档 |
| `http://localhost:8022/api/chat`   | 对话接口                |
| `http://localhost:8022/api/memory` | 记忆管理接口            |

------

> **注意**：路径中含**双空格** `F:\kimi  project`，shell 指令里必须加引号，否则报路径找不到。
